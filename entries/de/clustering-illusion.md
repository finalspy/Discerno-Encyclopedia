## Wie es funktioniert

Echter Zufall erzeugt Serien und Häufungen. Gilovich (1991) erklärt, dass man vom Zufall fälschlicherweise einen regelmäßigen Wechsel erwartet, sodass Häufungen eine Erklärung zu verlangen scheinen.

## Warum es problematisch ist

Eine Gruppe von Fällen auf einer Karte oder im Zeitverlauf kann eine verborgene Ursache zu haben scheinen. Sie kann tatsächlich eine haben, doch das muss überprüft werden.

## Wie man es erkennt

- Eine Häufung wird ohne Vergleich als Beweis angeführt.
- Das Gebiet oder der Zeitraum wird erst im Nachhinein festgelegt.

## Wie man sich schützt

- Berechnen, was der Zufall erzeugen würde.
- Das Muster an anderen Daten testen.
