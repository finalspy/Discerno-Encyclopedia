## How it works

The synthesis by Cepeda and colleagues (2006) confirms this advantage of distributed practice over time.

## Why it is problematic

This is not a reasoning bias in the strict sense, but a useful memory effect: spaced repetition serves to learn, and the same mechanism can be used to make a message stick.

## How to detect it

- A message returns at regular intervals over time.

## How to protect yourself

- Use it to learn, for example to retain these entries.
- Ask why the same message keeps coming back.
